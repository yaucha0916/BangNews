# BangNews
This is a RSS reader including news of Taiwan.You can input some keyword you want to block.This app will filter out unwanted news for you.

## Firebase configuration

The bundled GoogleService-Info.plist contains a placeholder API_KEY. Firebase
initialization and dependencies are currently commented out in this project.
If Firebase is re-enabled, supply your own restricted client API key locally;
do not commit its value. Never put a service-account private key in the app.

The former Google API key remains in earlier Git commits. Removing it from the
latest files does not revoke the key or purge history. The project owner must
review its Google Cloud API/application restrictions and rotate or revoke it if
necessary. Firebase client API keys identify a project; database access must
also be protected with Firebase Security Rules and App Check.
